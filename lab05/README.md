# Лабораторная работа №5

**Тема:** сравнительный анализ архитектуры цифровых систем.

**Цель работы:** научиться анализировать цифровые продукты разных классов, выделять основные компоненты веб-систем, обоснованно предполагать архитектурный подход и сравнивать архитектурные решения по масштабируемости, отказоустойчивости и сложности сопровождения.

## Выбранные цифровые продукты

В демонстрационном примере рассмотрены три продукта, которые не входят в варианты лабораторной работы:

| Продукт | Класс системы |
|---|---|
| Wikipedia | Информационный веб-проект с совместным редактированием |
| Shopify | SaaS-платформа электронной коммерции |
| Booking.com | Многосторонняя платформа онлайн-бронирования |

## Выполненная работа

В ходе лабораторной работы:

1. Изучены назначение, пользователи и ключевые функции трёх цифровых продуктов.
2. Для каждого продукта описан характерный пользовательский сценарий.
3. Выделены интерфейс, прикладная логика, данные, интеграции и инфраструктура.
4. Построены упрощённые логические схемы взаимодействия компонентов.
5. Сформулированы и обоснованы предполагаемые архитектурные подходы.
6. Системы сравнены по масштабируемости, отказоустойчивости и сложности сопровождения.
7. Определены основные архитектурные компромиссы и сформулированы сравнительные выводы.

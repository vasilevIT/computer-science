# Лабораторная работа №4

**Тема:** Анализ учебного набора данных с помощью SQL.

**Предметная область:** сервис аренды велосипедов.

**Цель работы:** научиться анализировать данные из нескольких связанных таблиц с помощью SQL, применять фильтрацию, сортировку, агрегирование, группировку и объединение таблиц, проверять корректность результатов и формулировать аналитические выводы.

## Описание предметной области

Рассматривается сервис аренды велосипедов, который хранит информацию о клиентах, велосипедах и совершённых арендах.

Учебная база данных содержит три связанные таблицы:

- `customers` — информация о клиентах сервиса.
- `bicycles` — информация о велосипедах и стоимости аренды.
- `rentals` — история аренды велосипедов клиентами.

Для анализа используется SQLite в онлайн-среде SandboxSQL.

## Выполненная работа

В ходе лабораторной работы:

1. Изучена структура учебной базы данных.
2. Сформулированы аналитические вопросы.
3. Выполнены SQL-запросы с `WHERE` и `ORDER BY`.
4. Рассчитаны агрегированные показатели с помощью `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`.
5. Выполнена группировка с `GROUP BY` и фильтрация групп с `HAVING`.
6. Исследованы связи таблиц с помощью `INNER JOIN` и `LEFT JOIN`.
7. Проверена корректность результатов и сформулированы аналитические выводы.

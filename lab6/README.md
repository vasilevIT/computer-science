# Лабораторная работа №6

**Название:** Анализ платформенного решения (CMS/low-code)  
**Платформа:** Ghost CMS  
**Учебный продукт:** «Журнал городского садоводства»  
**Статус:** демонстрационный пример, не совпадает с вариантами 1–10.

**Цель:** исследовать устройство платформы, её компоненты, способы настройки и интеграции, ограничения и применимость к разным проектам.

В [аналитическом отчёте](report/analysis.md) приведены структура интерфейса, модель контента, интеграции, логическая схема, анализ рисков и рекомендации.

**Иллюстрации:** [логическая схема](images/product_scheme.png), [учебный макет интерфейса](images/interface_example.png). Макет не является скриншотом реальной панели Ghost.

Пример подготовлен на основе открытых описаний и проектных предположений; тестирование платформы не проводилось.
